# New POS System (가칭)

캐나다 **주유소·편의점·그로서리**용 오픈소스 POS (Windows 11). 1차 대상은 **서스케치원**이며 북미 전역으로 확장할 수 있게 설계했습니다.

> **상태: v0.1.0 시범판.** 계산대 1대 단독 운영. 카드 결제사·주유기·저울 연동과 현장 장비 테스트는 아직 하지 않았습니다.
> 시범 운영 전 실제 영업에 사용하지 마십시오.

## 설치

1. **Releases**에서 `New-POS-System-Setup-<버전>.exe`를 내려받습니다.
2. 실행합니다. 코드 서명이 없어 SmartScreen 경고가 나오면 *추가 정보 → 실행*을 누릅니다.
3. 데모 로그인: 계산원 **6** / PIN **1234**(관리자), 계산원 **1** / PIN **1111**(계산원). **실제 사용 전 설정에서 PIN을 바꾸십시오.**

## 사용 방법 (요약)

| 작업 | 방법 |
|---|---|
| 상품 판매 | 바코드 스캔 또는 번호 입력 후 **PLU / 입력** |
| 수량 | 수량 입력 → **수량 ×** → 상품 입력 |
| 부서 판매 | 금액 입력(예: 250 = $2.50) → 부서 버튼 |
| 오류 정정 | 줄을 눌러 선택 → **오류 정정** (선택 없으면 마지막 줄) |
| 결제 | **소계 / 결제** → 현금(받은 금액 또는 빠른 금액) / 카드(별도 단말기 승인 후) |
| 상품 등록·수정 | **상품 관리** (원가 → 마진율 계산, 기간 세일, 보증금, 연령 제한, 한글 상품명) |
| 파일 가져오기 | **가져오기** (CSV, 주간·월간 세일 TXT, L-BOSS SIL), 미리보기 후 적용 |
| 일 마감 | **보고서** (매출·세금·결제 수단·보증금·반올림·재출력) |
| 프린터·매장 정보 | **설정** (화면 미리보기 / Windows 프린터 / 네트워크 ESC/POS) |

## 아직 포함되지 않은 것

- 카드 결제사 연동 (예정: Stripe Terminal → Moneris → Global Payments)
- 주유기 컨트롤러 연동 (FUEL은 현재 금액 입력 부서 키)
- 저울·시리얼 장비 드라이버, 다중 계산대·매장 서버·본사 동기화
- 확인 필요 세금 항목: SK 기본 식료품 PST 범위, 보증금·EHC 과세, 유류세 처리, CRA 반올림·영수증 요건
- 설치 파일 코드 서명
